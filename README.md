## 🧩 Features

<details open>
<summary><b>Alerts &amp; Notifications</b></summary>

<br>

- **Notification center:** a bell icon with an animated red dot for anything unread. It keeps mod announcements and important game alerts in one place.
- **On-screen alerts:** clear, title-style alerts you can move, resize and restyle.
- **Original alert sounds:** a unique sound for each alert type, each one changeable, with a volume slider and a **mute button**.
- **Private message alerts:** get notified even when the game window isn't focused.
- **Tool durability warning:** know before your gathering tool breaks.
- **Low health alert:** pick the health level that triggers it.
- **Update alerts:** get told when a new version is out, with a direct download link.

</details>

<details>
<summary><b>Quests</b></summary>

<br>

- Full in-game **quest guide** with pictures and a zoomable viewer.
- **Quest panel** on your HUD, with translation and spoiler-protected pictures you can pin.
- **Click any coordinates** to point your compass there.
- Quest checklist to track your progress.

</details>

<details>
<summary><b>Wynncraft tools</b></summary>

<br>

- **Player lookup**, **global search** and **leaderboards**.
- **Ability map:** see any player's ability tree (when they've made it public).
- **World hopper** with player counts, favourites and quick switching.
- **Guild &amp; friends:** online guild members and your watchlist.

</details>

<details>
<summary><b>Items &amp; Builds</b></summary>

<br>

- **Roll score:** see how good a mythic's rolls are, right in the tooltip.
- **Market prices** on hover, with optional Shift-to-show.
- **Share your build:** create a build planner link from the gear you're wearing.
- **Favourite rewards:** get notified when an item you want is in this week's rewards.

</details>

<details>
<summary><b>Controls &amp; Gameplay</b></summary>

<br>

- **Auto sprint** and **auto reconnect**.
- **Command keys:** bind any command to a key.
- **FullBright**, plus client-side **time and weather** control.
- Ability tree **translation**.

</details>

<details>
<summary><b>Interface</b></summary>

<br>

- Modern settings menu with **search**, a guided **welcome tour** and **accent colours**.
- **HUD editor:** drag, scale, align and snap every element.
- Session, gathering, FPS and ping displays.
- **Backups:** export, import and restore all your settings with a code.
- Quick access from the **pause menu**.

</details>

## 📦 Installation

1. Install **[Fabric Loader](https://fabricmc.net/use/)** for **Minecraft 1.21.11**.
2. Download **[Fabric API](https://modrinth.com/mod/fabric-api)** for 1.21.11.
3. Download the latest **[JQoL release](https://github.com/TheRealJ2D/JQoL/releases/latest)**.
4. Put both `.jar` files in your `.minecraft/mods` folder.
5. Launch the game with the Fabric profile and join `play.wynncraft.com`.

> [!TIP]
> Open the JQoL menu from the icon on the **pause menu**, or by typing `/jqol`.

### Requirements

| | Version |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.18.1 or newer |
| Fabric API | Any version for 1.21.11 |
| Java | 21 or newer |

**Recommended:** Mod Menu and Cloth Config, to open settings from the mods list.

## ⌨️ Commands

| Command | Description |
|---|---|
| `/jqol` | Open the JQoL menu |
| `/jqol notifications` | Open your notifications |
| `/jqol mute` | Mute or unmute all JQoL sounds |
| `/jqol update` | Check for a new version |
| `/jqol search [query]` | Search players, guilds, items and more |
| `/jqol leaderboard` | Browse leaderboards |
| `/jqol abilities [player]` | View a player's ability map |
| `/jqol build` | Share your current build as a link |
| `/jqol worlds` | Open the world hopper |
| `/jqol social` | Guild members and your watchlist |
| `/jqol quests` | Open the quest checklist |
| `/jqol fav add/remove/list` | Manage favourite reward items |

> Every key can be changed in **Options → Controls → Key Binds → JQoL**.

## ❓ FAQ

<details>
<summary><b>Is JQoL client-side only?</b></summary>
<br>
Yes. It runs only on your game and doesn't need anything installed on a server.
</details>

<details>
<summary><b>Can I use it with other Wynncraft mods?</b></summary>
<br>
Yes. JQoL is built to work alongside other popular mods.
</details>

<details>
<summary><b>How do I update?</b></summary>
<br>
JQoL tells you in game when a new version is out. Click <b>[Download]</b> in chat, then replace the old JQoL jar in your <code>mods</code> folder with the new one.
</details>

<details>
<summary><b>Can I turn the sounds off?</b></summary>
<br>
Yes. Click the speaker icon at the top of the JQoL menu, use <code>/jqol mute</code>, or change each sound under <b>Chat &amp; Alerts → Alert Sounds</b>.
</details>

<details>
<summary><b>I found a bug or have an idea</b></summary>
<br>
Please <a href="https://github.com/TheRealJ2D/JQoL/issues">open an issue</a>. Include your game version, JQoL version and steps to reproduce it.
</details>
